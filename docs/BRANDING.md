# Riplow Branding

Riplow uses a monochrome, rounded, mobile-first identity.

- Primary mark: white R glyph on a near-black field.
- UI: black, charcoal, white, and subtle borders.
- Launcher icon: adaptive Android icon using the Riplow mark.
- The vector mark is bundled in the Android app and scales cleanly across launcher densities.
- Avoid neon/RGB treatment in the core product UI.
